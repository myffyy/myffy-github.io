# myffy — цифровая визитка

Персональная страница для NFC-метки с аватаром, ссылкой на [Telegram](https://t.me/myffy), светлой и тёмной темами. Статический HTML/CSS/JavaScript без сборки и внешних зависимостей.

## Локальный запуск

Из корня проекта:

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080. Для отдельного просмотра экрана загрузки: http://localhost:8080/loading.html.

## Возможности

- Адаптивная визитка с локальным шрифтом Space Grotesk.
- Единые логотип, размеры и расположение шапки на основной странице и экране загрузки, включая мобильную версию.
- Переключение LIGHT / DARK с сохранением выбора в `localStorage` и восстановлением темы до отображения страницы.
- Статус ONLINE ежедневно с 10:00 до 00:00 по Москве; в остальное время OFFLINE. Статус обновляется автоматически, его цвет отражается на индикаторе и обводке аватара.
- Автоматическое обновление года в подвале, эффекты наведения для аватара и кнопки Telegram.

## Экран загрузки

`index.html` показывает `loading.html` в iframe поверх визитки. Экран ожидает подготовки аватара и шрифта (до 5,5 секунды), отображает неравномерный прогресс минимум 2,8 секунды, затем сообщение `CONNECTION ESTABLISHED.` и галочку на 100% в течение секунды. После этого iframe плавно исчезает за 350 мс.

Основная страница принимает сообщение о завершении только от своего iframe и с того же origin. Во время загрузки её содержимое недоступно для взаимодействия. Защитный тайм-аут снимает экран через 8 секунд плюс время исчезновения, даже если загрузчик не ответил.

Без JavaScript визитка доступна сразу. На отдельно открытой `loading.html` есть ссылка `OPEN PERSONAL SPACE`: без JavaScript она видна сразу, с JavaScript — после завершения загрузки.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Визитка и iframe загрузчика |
| `common.css` | Шрифты, палитры, базовые стили, общие шапка и логотип |
| `style.css` | Адаптивная сетка визитки, эффекты и отображение iframe |
| `script.js` | Переключение темы, год и статус по московскому времени |
| `theme.js` | Восстановление темы и цвета интерфейса браузера |
| `loading.html` | Самостоятельный экран подключения |
| `loading.css` | Оформление индикатора и прогресса |
| `loading.js` | Подготовка ресурсов, прогресс и сообщение родительской странице |
| `loader.js` | Управление iframe, проверка сообщений и защитный тайм-аут |
| `images/avatar.png` | Аватар |
| `fonts/` | Space Grotesk и лицензия SIL OFL |

`PROMPT.md` — локальный рабочий файл, исключённый из Git через `.gitignore`.

## Публикация и NFC

Репозиторий предназначен для статического хостинга, включая GitHub Pages. Публикуйте HTML/CSS/JS-файлы вместе с папками `images/` и `fonts/`, сохраняя относительные пути. Серверная часть и установка пакетов не нужны.

После публикации запишите публичный HTTPS-адрес основной страницы на NFC-метку как URL.
