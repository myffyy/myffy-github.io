# myffy — цифровая визитка

Статический сайт без зависимостей. Откройте `index.html` или запустите:

```sh
python3 -m http.server 8080
```

Локальный адрес: http://localhost:8080

## Структура

- `index.html` — разметка визитки, включая iframe экрана загрузки.
- `style.css` — оформление и адаптивная сетка визитки.
- `script.js` — переключатель темы, год и статус по московскому времени.
- `loading.html` — самостоятельная страница подключения.
- `loading.css` — оформление страницы подключения.
- `loading.js` — прогресс, вращение индикатора, галочка и пауза на 100%.
- `loader.js` — показ и закрытие iframe, проверка сообщений, защитный тайм-аут.
- `common.css` — общие шрифты, палитра, базовые стили.
- `theme.js` — восстановление выбранной темы до отображения обеих страниц.
- `images/` — аватар; `fonts/` — локальный Space Grotesk и лицензия SIL OFL.

При открытии визитки `loading.html` показывается поверх основного содержимого. После подготовки аватара и шрифта, неравномерного прогресса (минимум 2,8 секунды) и секунды на 100% iframe плавно закрывается. Сообщения принимаются только от собственного iframe. При сбое основной контакт разблокируется через 8 секунд. Без JavaScript визитка доступна сразу, а `loading.html` содержит ссылку на неё.

При публикации загрузите все HTML/CSS/JS-файлы и папки `images`, `fonts` на статический хостинг. Запишите публичный HTTPS-адрес визитки на NFC-брелок как URL.
